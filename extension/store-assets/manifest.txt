Ashley Bridge 2.0.0: store assets

Made 2026-09-29. The screenshots are the real built extension (extension/.output/chrome-mv3, the release
build that the store zips are made from) loaded into Playwright's Chromium (Chrome for Testing 153) with
a 1280x800 viewport, light colour scheme, driven against the mock Open OnDemand portal
(extension/mock-ood/server.mjs) served over https on localhost with a self-signed certificate, the mock
user st1234, MOCK_LOGGED_IN=false so the Claude sign-in step is reached, and a three-day trial key issued
for that username with the vendor tool. The mock home was seeded with .hpcworker/profile.json and
.hpcworker/VERSION = 2 so the strip found the tool installed at the bundled version. No request went to
Anthropic: every claude.ai / claude.com navigation was answered locally by the test harness. The browser's
native permission prompt was accepted through Windows UI Automation (the Allow button), not by editing
any state. Nothing in the images was drawn by hand or composited.

Note on 01b-agreement-statements.png: the licence card below the dialog names wayne.edu as its example of
a site-key domain (extension source, src/ui/options.ts). Prefer 01 for the stores unless that example is
changed; the product itself carries no university name.
Note on 05-setup-page.png: captured from "3. Your portal" down. The page top after setup shows the saved key in
the input field in the clear, so it is not captured; 01 shows the page top before setup.
Note on 02-checks.png: check 1 reads WARN because the withdrawn-keys list is not published yet (the daily GET
met a 404 and the extension keeps working on no list, as designed); it turns OK once
https://openspineconsortium.com/ashley/bridge-killlist.json exists. The other sixteen are OK.
Note on the grey log box in 03, 03b and 04: it is the strip's own output box showing the last shell command's
output (the mock's probe submission), and the mock tool prints the mock home's path on the machine that made
the screenshots. Against a real portal that box shows the cluster path. Nothing was hidden or cropped.
